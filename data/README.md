# Data

Prepared analysis files for this study. This folder does not contain upstream Stata extracts. `coder_ratings.rds` is not in the source folder, so Table S3 uses the published kappa means.

Source directory: `TikTok_gh/data/` (sibling of this study, under the TikTok project).

| File | Role | Approx. size |
|---|---|---|
| `wave_9.rds` | Wave 1 video–respondent rows | ~63 MB |
| `wave_10.rds` | Wave 2 video–respondent rows | ~55 MB |
| `df_w9_w10.rds` | Respondent panel (attrition, party ID, PTV) | ~4 MB |
| `sample_overview.rds` | Sample-construction counts (not a numbered exhibit) | small |
| `comment_classification.csv` | Platform-comment codes for Figure S2 | ~0.4 MB |

All of the above are tracked in git (each under 100 MB).
