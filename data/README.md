# Data

Local copies of the prepared analysis files. This folder does not contain upstream Stata extracts. `coder_ratings.rds` is not in the source folder, so Table S3 uses the published kappa means.

Source directory: `TikTok_gh/data/` (sibling of this study, under the TikTok project).

| File | Role |
|---|---|
| `wave_9.rds` | Wave 1 video–respondent rows |
| `wave_10.rds` | Wave 2 video–respondent rows |
| `df_w9_w10.rds` | Respondent panel (attrition, party ID, PTV) |
| `sample_overview.rds` | Sample-construction counts (not a numbered exhibit) |
| `comment_classification.csv` | Platform-comment codes for Figure S2 |

The four large or respondent-level files are listed in `.gitignore`. `sample_overview.rds` is a small aggregate table.
